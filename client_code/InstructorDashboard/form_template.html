How does this actually work?

This uses a simplified "bag-of-words" Naive Bayes classifier: it counts how often each word appears with each intent label in the training data, then for a new sentence, multiplies together how likely each of its words is under each label (with a small correction called Laplace smoothing so unseen words don't break the math), and picks the label with the highest resulting probability. It has no idea about word order, grammar, or meaning beyond word counts — which is exactly why certain sentences trip it up.
